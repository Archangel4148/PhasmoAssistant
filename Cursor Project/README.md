# Phasmophobia Companion

Offline-first desktop companion and overlay for Phasmophobia.

## Prerequisites

- [Node.js](https://nodejs.org/)
- [Rust](https://www.rust-lang.org/learn/get-started)
- [Tauri prerequisites (Windows)](https://tauri.app/start/prerequisites/)

## Development

```powershell
npm install
npm run tauri dev
```

## Scripts

| Command | Description |
|---------|-------------|
| `npm run dev` | Vite dev server only |
| `npm run tauri dev` | Full Tauri desktop app |
| `npm run typecheck` | TypeScript strict check |
| `npm run build` | Production frontend build |

See `SPEC.md` for the full product specification and phased development plan.
